API Documentation

Complete reference for the <aegov-pagination> component.

Properties

Property Attribute Type Default Description
totalPages total-pages number 1 Total number of pages
currentPage current-page number 1 Currently active page (1-indexed). Update on every aegovPageChange event.
variant variant 'default' | 'compact' 'default' Display variant. compact shows only prev/next with a page indicator.
size size 'sm' | 'base' | 'lg' 'base' Size variant controlling button height and font size.
showFirstLast show-first-last boolean false Show First and Last navigation buttons.
siblingCount sibling-count number 1 Number of sibling pages shown on each side of the current page.
boundaryCount boundary-count number 1 Number of pages always visible at each boundary (start and end).
disabled disabled boolean false Disables all pagination interaction.
prevLabel prev-label string 'Previous' Label for the Previous button.
nextLabel next-label string 'Next' Label for the Next button.
firstLabel first-label string 'First' Label for the First button (when show-first-last is enabled).
lastLabel last-label string 'Last' Label for the Last button (when show-first-last is enabled).

Events

Event Detail Type Description
aegovPageChange number Emitted when a page is selected. Detail is the new page number (1-indexed). Update current-page in response.

Accessibility

Feature Details
ARIA Label <nav aria-label="Pagination"> wraps the component.
Current Page aria-current="page" marks the active page button.
Disabled State aria-disabled="true" and disabled on inactive nav buttons.
Button Labels Each button has a descriptive aria-label (e.g., "Go to page 3", "Go to previous page").
Live Region Compact variant indicator uses aria-live="polite" for screen reader updates.
RTL Directional icons automatically flip in RTL layouts via CSS transform.
