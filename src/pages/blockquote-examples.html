A semantic blockquote component for displaying quotations with citations, author attribution, and customizable styling.

📚 API Documentation

Properties

Property Type Default Description
variant BlockquoteVariant 'primary' Visual style: 'primary' (with quote icon) or 'colored'/'coloured' (with background)
cite string undefined URL of the source/citation for the quotation (semantic HTML)
author string undefined Name of the quote author
author-title string undefined Title, position, or description of the author

Slots

Slot Description
default The quote content (supports text, paragraphs, lists, and inline formatting)

CSS Parts

Part Description
blockquote The native <blockquote> element (for external styling)

Usage Examples

Use Case Code Example

📝 Important Notes:

Variants: Both "colored" and "coloured" spellings are supported for the variant property.

Quote Icon: The decorative quote icon only appears in the 'primary' variant. The 'colored' variant uses a background color and left border instead.

Rich Content: The default slot supports rich HTML including paragraphs, lists, and inline formatting elements.

RTL Support: The quote icon automatically flips horizontally in RTL mode. All spacing and alignment adapts automatically.

Semantic HTML: Uses the native <blockquote> element with cite attribute for proper semantic markup and SEO.
