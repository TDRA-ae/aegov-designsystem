🧭 Breadcrumbs Component

Navigation component showing hierarchical page location with parent-child architecture

Parent-Child Pattern Separator Styles Text Truncation Link Targets SEO Microdata RTL Support Accessibility

1. Basic Breadcrumbs (Slash Separator)

Default breadcrumb navigation with slash separator. Items with href render as links, item without href is the current page.

Enable the microdata property to add schema.org structured data for better SEO.

Home Blog Technology Web Components Guide
<aegov-breadcrumbs microdata> <aegov-breadcrumbs-item href="/">Home</aegov-breadcrumbs-item> <aegov-breadcrumbs-item href="/blog">Blog</aegov-breadcrumbs-item> <aegov-breadcrumbs-item href="/blog/technology">Technology</aegov-breadcrumbs-item> <aegov-breadcrumbs-item>Web Components Guide</aegov-breadcrumbs-item> </aegov-breadcrumbs>
📊 SEO Benefits:

The microdata property adds schema.org/BreadcrumbList structured data that search engines use to display breadcrumbs in search results.

📚 Complete API Documentation

Parent Component: <aegov-breadcrumbs>

Property Type Default Description
separator 'slash' | 'chevron' 'slash' The separator style to use between breadcrumb items
max-length number undefined Maximum number of characters before truncating breadcrumb item text with ellipsis (…). If not set, text will not be truncated.
microdata boolean false Whether to add schema.org/BreadcrumbList microdata for SEO structured data

Child Component: <aegov-breadcrumbs-item>

Property Type Default Description
href string undefined The URL that the breadcrumb item links to. If not provided, the item will be rendered as plain text (current page).
target LinkTarget '_self' Where to open the linked document (_self, _blank, _parent, _top)

Events

Event Name Detail Type Description
aegovBreadcrumbItemClick { href?: string; event: MouseEvent } Emitted when a breadcrumb item is clicked. Contains the href value and the native MouseEvent. Call event.preventDefault() to prevent default navigation.

Slots

Slot Name Description
(default) Content of the breadcrumb item. Can be plain text or HTML elements (e.g., SVG icons)

⚠️ Important Notes:

• <aegov-breadcrumbs-item> must be used inside <aegov-breadcrumbs>
• Last item (without href) is automatically marked as current page with aria-current="page"
• Separators are decorative and marked with aria-hidden="true"
• Chevron separator automatically flips direction in RTL mode
• Parent component passes separator, maxLength, and microdata props to all children automatically
