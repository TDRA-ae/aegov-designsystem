Toast Component

Lightweight, non-intrusive notifications that appear temporarily to provide feedback.

Variants — Soft Appearance

Five semantic variants with soft (light) background. Click each to trigger.

<script> const toast = document.createElement('aegov-toast'); toast.variant = 'success'; toast.appearance = 'soft'; toast.innerHTML = 'Changes saved successfully!'; document.body.appendChild(toast); toast.show(); </script>

Variants — Solid Appearance

Same five variants with bold solid background.

Positions

Toast can appear in 6 screen positions. Each slides in from the nearest edge.

Stack Mode vs Rack Mode

Stack mode shows all toasts with gaps. Rack mode collapses them into a compact deck — hover to expand.

Rack + Duration (auto-dismiss)

Rack toasts with auto-dismiss. Each toast dismisses individually after its duration; the rack recalculates.

Rack + Actions Slot

Rack toasts with action buttons. Expand the rack to interact with actions on each toast.

<script> // Rack with auto-dismiss duration window.aegovToast.show({ message: 'Auto-dismiss in 4s', variant: 'info', mode: 'rack', duration: 4000, showProgress: true, }); // Rack with action slot const toast = document.createElement('aegov-toast'); toast.variant = 'info'; toast.mode = 'rack'; toast.duration = 0; toast.innerHTML = ` New update available <a slot="actions" href="#">Update Now</a> `; document.body.appendChild(toast); toast.show(); </script>

Progress Bar

Optional countdown progress bar showing remaining time before auto-dismiss.

Duration & Persistent

Auto-dismiss after a configurable duration. Set duration="0" for persistent toasts (dismiss manually).

Options

Hide the icon or remove the dismiss button for minimal notifications.

Actions Slot

Add action buttons inside the toast using the "actions" slot.

<aegov-toast variant="info" duration="0"> New version available <button slot="actions" onclick="...">Update Now</button> </aegov-toast>

Listen to toast lifecycle events: open, close, and dismiss.
