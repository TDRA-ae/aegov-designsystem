API Reference

aegov-input

A flexible text input component with support for multiple types, sizes, icon slots, password reveal, and clipboard copy.

PropertyAttributeTypeDefaultDescription
fieldIdfield-idstringautoUnique ID for the native input. Auto-generated if omitted.
typetypeInputType'text'Input type: text, email, password, tel, url, number, search, date, time, datetime-local, month, week
sizesizeInputSize'base'Size: sm (40px), base (48px), lg (52px)
valuevaluestring''Current value (mutable).
placeholderplaceholderstring—Placeholder text.
namenamestring—Form submission name.
disableddisabledbooleanfalseDisables the input. Label colour dims automatically inside aegov-form-field.
readonlyreadonlybooleanfalseMakes the input read-only.
requiredrequiredbooleanfalseMarks the field as required.
revealablerevealablebooleanfalseShows eye toggle to reveal/hide password. Only works when type="password".
copyablecopyablebooleanfalseShows copy-to-clipboard button. Only works when readonly is true.
classclassstring—Additional CSS classes merged onto the native input.

Events

EventDetailDescription
aegovInputInput{ value, event }Fires on every keystroke.
aegovInputChange{ value, event }Fires on blur or Enter (native change).
aegovInputFocusFocusEventFires when the input gains focus.
aegovInputBlurFocusEventFires when the input loses focus.

Slots

SlotDescription
icon-startIcon rendered inside the input border at the start (flips in RTL). Always visible.
icon-endIcon rendered inside the input border at the end (flips in RTL). Ignored when revealable or copyable is active.

Pass-through Attributes

The following attributes are forwarded to the native <input> element: pattern, min, max, minlength, maxlength, step, autocomplete, autofocus, inputmode, list, multiple, accept, capture, spellcheck, enterkeyhint, title, tabindex, form, plus all aria-* and data-* attributes.

aegov-form-field

Container that auto-links a child aegov-label to a child aegov-input via the for/id relationship. Also dims the label when the input is disabled.

aegov-label

PropertyAttributeTypeDescription

aegov-input-group

Wraps an aegov-input with visual prefix/suffix addons (text, buttons, or selects) sharing a single border ring.

PropertyAttributeTypeDefaultDescription
addonPrefixaddon-prefixstring—Text displayed before the input.
addonSuffixaddon-suffixstring—Text displayed after the input.
sizesizeInputSize'base'Propagated to child aegov-input and aegov-button.
classclassstring—Additional CSS classes for the group container.
Note: prefix and suffix are reserved HTML properties. Always use addon-prefix / addon-suffix as attributes.

3. Input Sizes

4. Disabled & Readonly States

Disabled inputs are non-interactive and visually dimmed. The label inside aegov-form-field automatically dims when the input is disabled. Readonly inputs display a value but prevent editing.

5. Icon Slots

Pass SVG icons via slot="icon-start" and slot="icon-end". Icons render inside the input border and support click interactions. Uses CSS logical properties so start/end automatically flip in RTL layouts.

Search (icon-start) Email (icon-start) Amount (icon-end) Both Icons (start + end)

6. Icon Slots — Sizes

Icon containers automatically match the input height. Control the icon size via Tailwind classes on the SVG element itself.

Small (sm) — w-4 h-4 icon Base (default) — w-5 h-5 icon Large (lg) — w-6 h-6 icon

7. Icon Slots — Priority

revealable and copyable action buttons always take priority over icon-end. If both are present, the user icon is ignored. The icon-start slot is always rendered regardless of action buttons.

Password with icon-start (icon-end ignored) Copyable with icon-start (icon-end ignored)
