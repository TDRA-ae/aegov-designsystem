OTP / Pin Input Component

Split input for OTP codes and PINs. Two visual variants, paste support with space stripping, pattern validation, and 6 size options.

Variants

Continuous (default) — single bordered box with dividers
Individual — separate bordered boxes per digit
<aegov-otp variant="continuous"></aegov-otp>
<aegov-otp variant="individual"></aegov-otp>

Lengths

3-digit PIN
4-digit PIN
5-digit OTP (default)
6-digit OTP
<aegov-otp length="3"></aegov-otp>
<aegov-otp length="6"></aegov-otp>

Sizes

Each size maps to a Tailwind text size: xs, sm, base, lg, xl, 2xl.

XS (text-xs)
SM (text-sm)
Base (text-base) — default
LG (text-lg)
XL (text-xl)
2XL (text-2xl)

Individual Variant Sizes

SM Individual
LG Individual
2XL Individual
<aegov-otp size="xs"></aegov-otp>
<aegov-otp size="lg" variant="individual"></aegov-otp>
<aegov-otp size="2xl"></aegov-otp>

Alphanumeric Mode

When alphanumeric is set, both letters and numbers are accepted.

Numeric only (default) — try typing letters
Alphanumeric — accepts letters and numbers
<aegov-otp alphanumeric></aegov-otp>

Paste Support

Paste any OTP value — spaces are automatically stripped. Try copying "1 2 3 4 5" and pasting into the input below.

Paste a 5-digit code (spaces allowed)
Copy this: 9 8 7 6 5 
<!-- Paste "9 8 7 6 5" — becomes "98765" -->
<aegov-otp></aegov-otp>

Pre-filled Value

Pre-filled with "42069"
Partial pre-fill "12"
<aegov-otp value="42069"></aegov-otp>

Pattern Validation

Define a regex pattern. When all cells are filled, the value is validated. Invalid entries fire aegovOtpInvalid.

Pattern: only "12345" accepted (^12345$)
<aegov-otp pattern="^12345$"></aegov-otp>
<aegov-otp pattern="^\d{4}$" length="4"></aegov-otp>

Disabled State

Disabled continuous
Disabled individual
<aegov-otp disabled value="12345"></aegov-otp>

Events

Event Detail Description
aegovOtpChange{ value: string }Fires on every character input or deletion.
aegovOtpComplete{ value: string }Fires when all cells are filled and valid.
aegovOtpInvalid{ value: string, pattern: string }Fires when pattern validation fails on complete.
