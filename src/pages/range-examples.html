API Reference

Properties

Property Attribute Type Default Description
fieldId field-id string auto Unique ID for the native range input element. Auto-generated if not provided.
name name string — The name attribute for the range, used in form submissions. In range mode, appends -low and -high.
value value number 50 Current value in single mode.
valueLow value-low number 25 Low thumb value. Only used when mode="range".
valueHigh value-high number 75 High thumb value. Only used when mode="range".
min min number 0 Minimum value of the range.
max max number 100 Maximum value of the range.
step step number 1 Step increment between values.
size size 'sm' | 'base' | 'lg' 'base' Track height: sm (4px), base (6px), lg (8px). Thumb size remains constant at 24×24.
display display 'none' | 'tooltip' | 'thumb' | 'full' 'none' Value display mode. none: no values shown. tooltip: floating label above thumb. thumb: value inside thumb. full: value in thumb + min/max labels.
orientation orientation 'horizontal' | 'vertical' 'horizontal' Layout direction. Vertical mode renders bottom-to-top (bottom = min, top = max).
mode mode 'single' | 'range' 'single' Single thumb or dual thumb for selecting a value range. Dual mode uses valueLow and valueHigh.
disabled disabled boolean false Disables the range slider. Reduces opacity and prevents all interaction.
required required boolean false Marks the range as required for form validation.
label label string — Optional label text rendered above the range slider.

Events

Event Detail (single) Detail (range) Description
aegovRangeInput { value: number } { valueLow: number, valueHigh: number } Emitted during drag on every value update. Use for real-time feedback.
aegovRangeChange { value: number } { valueLow: number, valueHigh: number } Emitted on mouse/touch release when the value is committed. Use for final updates.

Pass-through Attributes

The following attributes are passed through to the native <input type="range"> element: aria-*, data-*, tabindex, autofocus, title, form.

Accessibility

Keyboard Interaction

Key Action
Arrow Right / Up Increases the value by one step.
Arrow Left / Down Decreases the value by one step.
Home Sets the value to the minimum.
End Sets the value to the maximum.
Tab Moves focus to/from the range input. In dual mode, Tab moves between the low and high thumb inputs.

ARIA Attributes

  • The native <input type="range"> provides built-in screen reader support with aria-valuemin, aria-valuemax, and aria-valuenow.
  • aria-orientation is set to match the component's orientation prop.
  • In dual mode, each input has a descriptive aria-label: "Range minimum" and "Range maximum".
  • In dual mode, the low input's aria-valuemax is set to valueHigh, and the high input's aria-valuemin is set to valueLow, providing accurate range context.
  • The visual track, fill, and thumb elements are decorative; all semantic information comes from the native input.

Best Practices

  • Always provide an accessible name. Use the label prop, or wrap in aegov-form-field with aegov-label, or provide aria-label on the host element.
  • Use display="tooltip" or display="full" when the exact value matters to the user, such as price filters or volume controls.
  • Choose an appropriate step. A step of 1 is fine for 0–100 ranges, but use larger steps (e.g. 10, 50) for wide ranges to improve usability.
  • Dual mode for filters. Use mode="range" when the user needs to select a range (e.g. price range, date range). The thumbs cannot cross each other.
  • Vertical for specialized UI. Use orientation="vertical" for volume sliders, equalizers, or other contexts where vertical makes more sense. Set a height via CSS --range-height custom property.
