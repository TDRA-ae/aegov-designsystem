Toast Component

Clean notification toasts with variant-colored top borders. Soft (white) and Solid (black) appearances. Supports title, description, icon, and action slots.

Variants — Soft Appearance

White background, black text. The variant is indicated by a bold 4px colored top border.

<aegov-toast variant="success">
  <span slot="icon">...</span>
  <span slot="title">Success</span>
  Changes saved successfully!
</aegov-toast>

Variants — Solid Appearance

Black background, white text. Same colored top border per variant.

Slots — Title, Description & Icon

The toast supports three content slots: icon, title, and the default slot (description). All are optional.

Description only (default slot)

Title + Description

Icon + Title + Description

<aegov-toast variant="error" duration="0">
  <svg slot="icon" ...>...</svg>
  <span slot="title">Upload Failed</span>
  The file exceeded the maximum size limit.
</aegov-toast>

Actions Slot

Add action buttons or links inside the toast using slot="actions". They render below the description.

<aegov-toast variant="info" duration="0">
  <span slot="title">New version available</span>
  Please update to get the latest features.
  <a slot="actions" href="#">Update Now</a>
</aegov-toast>

Positions

Toast slides in from the nearest edge. Six screen positions available.

Progress Bar

Optional countdown bar showing time remaining before auto-dismiss. Pauses on hover.

Duration & Persistent

Auto-dismiss after a set duration. Use duration="0" for persistent toasts that stay until manually dismissed.

Dismiss Button

The dismiss button is shown by default. Set dismissible="false" to hide it.

Stack Mode vs Rack Mode

Stack mode shows all toasts with gaps between them. Rack mode collapses toasts into a compact deck — hover to expand.

Stack Mode

Rack Mode

Rack + Auto-dismiss + Progress

Rack + Actions

// Rack mode
const toast = document.createElement('aegov-toast');
toast.variant = 'info';
toast.mode = 'rack';
toast.position = 'top-right';
toast.duration = 0;
toast.innerHTML = '<span slot="title">Title</span>Description';
document.body.appendChild(toast);
toast.show();

Listen to toast lifecycle events: aegovToastOpen, aegovToastClose, aegovToastDismiss.

Global Helper — window.aegovToast.show()

Quick one-liner from anywhere in your app.

window.aegovToast.show({
  message: 'File uploaded!',
  variant: 'success',
  duration: 3000,
  showProgress: true
});
