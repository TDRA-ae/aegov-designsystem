Avatar Variants

Two shape variants: Square (with rounded corners) and Rounded (fully circular)

Square (Default) Rounded corners for modern look <aegov-avatar variant="square">
Rounded Fully circular avatar <aegov-avatar variant="rounded">

Status Indicators

Display online/offline status with color-coded indicators

Online Status Green indicator for online users <aegov-avatar status="true" status-type="online">
Offline Status Red indicator for offline users <aegov-avatar status="true" status-type="offline">
No Status No indicator displayed <aegov-avatar status="true" status-type="none">
Default (No Status) Status disabled by default <aegov-avatar>

Comment Section

Base size square avatar for comments
