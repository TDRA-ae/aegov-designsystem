3. Push vs Overlay Mode

Control how banners interact with page content: push mode reserves space, overlay mode floats over content.

Push Mode (Takes Space)

Overlay Mode (Floats)

Mode Comparison:

• Push Mode: Banner takes up space in page flow, pushing content down/up. Default behavior.

• Overlay Mode: Banner floats over content. Emits aegovBannerHeightChange event for body padding adjustment.

4. Push + Fixed Mode (Automatic Body Padding) ✨

When using fixed positioning with push mode, the body automatically gets padding applied using CSS :has() selector. Watch the content shift as banners are added/removed!

Fixed Top + Push

Fixed Bottom + Push

Watch This Content Shift!

This content area will be pushed down when you add a top banner, and pushed up when you add a bottom banner. The body padding is applied automatically using CSS :has() selector with dynamic CSS variables.

Current body padding-top: 0px

Current body padding-bottom: 0px

How it works:

• Component sets CSS variable: --banner-fixed-top-height or --banner-fixed-bottom-height

• CSS :has() selector detects banner: body:has(aegov-banner.banner--fixed.banner--top.banner--push)

• Body padding applied automatically: padding-top: var(--banner-fixed-top-height, 0)

• ResizeObserver updates padding if banner content changes

• Smooth 300ms transition for padding changes
