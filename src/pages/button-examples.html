API Documentation

Properties

Property Attribute Type Default Description
variant variant 'solid' | 'outline' | 'soft' | 'link' 'solid' The button variant style
appearance appearance 'primary' | 'secondary' | 'danger' | 'neutralMin' | 'neutralMax' 'primary' The button appearance (color scheme)
size size 'xs' | 'sm' | 'base' | 'lg' 'base' The button size
type type 'button' | 'submit' | 'reset' 'button' The button type attribute
disabled disabled boolean false Whether the button is disabled
loading loading boolean false Whether the button is in a loading state (shows spinner)
icon icon boolean false Whether the button is icon-only (square shape)
full full boolean false Whether the button should take full width
bold bold boolean true Whether the button text should be bold

Events

Event Type Description
aegovButtonClick CustomEvent<MouseEvent> Emitted when the button is clicked (not emitted if disabled or loading)
aegovButtonFocus CustomEvent<FocusEvent> Emitted when the button receives focus
aegovButtonBlur CustomEvent<FocusEvent> Emitted when the button loses focus

Slots

Slot Description
(default) Button content (text, icons, or any HTML)
