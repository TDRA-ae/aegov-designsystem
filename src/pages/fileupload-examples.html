File Upload

Three variants for file selection: styled input, button trigger, and drag-and-drop zone. With validation, size options, and file management.

1 Default Variant

A styled file input with a browse button. Behaves like a native file input — each new selection replaces the previous one.

Multiple files
<aegov-fileupload label="Profile photo" accept=".jpg,.png,.webp" max-file-size="5242880"></aegov-fileupload> <aegov-fileupload label="Attachments" multiple accept=".pdf,.doc,.docx" description="Upload supporting documents"></aegov-fileupload>

2 Button Variant

A styled button triggers file selection. Selected files appear below with name, size, and a remove button. New selections accumulate.

Single file
Multiple files with max
<aegov-fileupload variant="button" label="Upload document" accept=".pdf"></aegov-fileupload> <aegov-fileupload variant="button" label="Supporting files" multiple max-files="3" accept=".pdf,.jpg,.png" description="Upload up to 3 files"></aegov-fileupload>

3 Dropzone Variant

A drag-and-drop area with a browse button fallback. Files can be dropped or selected manually. The file list appears inside the drop zone.

Single file dropzone
Multiple files dropzone
<aegov-fileupload variant="dropzone" label="Certificate" accept=".pdf" max-file-size="10485760"></aegov-fileupload> <aegov-fileupload variant="dropzone" label="Project files" multiple accept="image/*,.pdf" description="Drag images or PDFs into the area below"></aegov-fileupload>

4 Sizes

All three variants support sm, base (default), and lg sizes. The size affects input height, button dimensions, text size, and file list spacing.

5 File Type Helpers

Helper text is auto-generated from the accept prop. Use helper-text to provide a custom override.

Auto-generated from extensions
Auto-generated from MIME wildcards
Custom override
<!-- Auto-generated --> <aegov-fileupload accept=".pdf,.jpg,.png,.docx" label="Documents"></aegov-fileupload> <!-- MIME wildcard --> <aegov-fileupload accept="image/*" label="Photos"></aegov-fileupload> <!-- Custom override --> <aegov-fileupload accept=".pdf" helper-text="Only PDF files under 10MB are accepted" label="Legal documents"></aegov-fileupload>

6 Disabled State

All variants support a disabled state that prevents interaction.

7 Event Handling

The component emits aegovFileuploadChange, aegovFileuploadRemove, and aegovFileuploadError events.

Waiting for events...
const upload = document.querySelector('aegov-fileupload'); upload.addEventListener('aegovFileuploadChange', (e) => { console.log('Files:', e.detail.files); }); upload.addEventListener('aegovFileuploadRemove', (e) => { console.log('Removed:', e.detail.file.name); console.log('Remaining:', e.detail.remaining); }); upload.addEventListener('aegovFileuploadError', (e) => { console.log('Error:', e.detail.type, e.detail.message); });

8 RTL Support

All variants work correctly in right-to-left layouts.

9 API Reference

Properties

Property Attribute Type Default Description
variant variant 'default' | 'button' | 'dropzone' 'default' Display variant
size size 'sm' | 'base' | 'lg' 'base' Component size
multiple multiple boolean false Allow multiple file selection
accept accept string — Accepted file types (e.g. .pdf,.jpg,image/*)
maxFileSize max-file-size number — Max file size in bytes. Fires error event if exceeded
maxFiles max-files number — Max number of files (multiple mode). No limit by default
disabled disabled boolean false Disables the component
required required boolean false Marks the field as required
name name string — Form field name
fieldId field-id string auto Unique ID for the native input
label label string — Label text above the control
description description string — Description text below the label
helperText helper-text string auto Custom helper text. Overrides auto-generated text from accept
buttonText button-text string varies Custom button text. Defaults: "Browse" / "Choose File(s)" / "Browse Files"

Events

Event Detail Description
aegovFileuploadChange { files: File[] } Emitted when file selection changes (add or remove)
aegovFileuploadRemove { file: File, remaining: File[] } Emitted when a file is removed from the list
aegovFileuploadError { type: string, file?: File, message: string } Emitted on validation failure. Types: max-size, max-files, invalid-type

Methods

Method Returns Description
getFiles() Promise<File[]> Returns the currently selected files
clear() Promise<void> Clears all selected files

Accessibility

Keyboard: In the default variant, the native file input remains focusable and keyboard-accessible (Tab, Enter/Space opens the file dialog). In button and dropzone variants, the trigger button is the keyboard target.

Screen readers: The native input is available to assistive technology in the default variant. Labels are linked via for/id. Remove buttons have descriptive aria-label attributes (e.g. "Remove filename.pdf").

Required state: The required attribute is passed to the native input. The visual asterisk is marked aria-hidden="true".

Error handling: Validation errors are emitted as events, allowing the consumer to display error messages in their preferred format and location.
