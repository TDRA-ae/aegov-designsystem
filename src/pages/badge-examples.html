API Documentation

Properties

Property Attribute Type Default Description
color color 'default' | 'primary' | 'secondary' | 'aegold' | 'aered' | 'aegreen' | 'aeblack' | 'techblue' | 'seablue' | 'camel' | 'desert' | 'fuchsia' | 'slate' | 'purple' | 'pink' | 'indigo' | 'lime' 'default' The badge color variant (17 options)
appearance appearance 'soft' | 'solid' 'soft' The badge appearance (soft = subtle, solid = bold)
size size 'sm' | 'base' | 'lg' 'base' The badge size
dismissible dismissible boolean false Whether the badge shows a dismiss button (emits event, doesn't auto-remove)

Events

Event Type Description
aegovBadgeDismiss CustomEvent<void> Emitted when the dismiss button is clicked. The badge does NOT auto-remove; you must handle removal in your code.

Slots

Slot Description
(default) Badge content (text, numbers, or any HTML)
