Height Variations

Height uses Tailwind spacing scale. Each unit = 0.25rem. Default is "2" (0.5rem / 8px).

height="1" (0.25rem / 4px)
height="1.5" (0.375rem / 6px)
height="2" (0.5rem / 8px) — default
height="3" (0.75rem / 12px)
height="4" (1rem / 16px)
height="6" (1.5rem / 24px)
height="8" (2rem / 32px)
<aegov-progress value="60" height="1"></aegov-progress>
<aegov-progress value="60" height="4"></aegov-progress>
<aegov-progress value="60" height="8"></aegov-progress>

Counter — Top Placement

Counter is placed above the bar on the right side.

Top counter (value only)
Top counter with "%" suffix
Top counter with " / 200" suffix
<aegov-progress value="42" counter="top"></aegov-progress>
<aegov-progress value="42" counter="top" counter-suffix="%"></aegov-progress>
<aegov-progress value="120" max="200" counter="top" counter-suffix=" / 200"></aegov-progress>

Counter — Trailing Placement

Counter is placed inline at the end of the bar, reducing the bar width slightly.

Trailing counter (value only)
Trailing counter with "%" suffix
Trailing counter with " MB" suffix

<aegov-progress value="75" counter="trailing" counter-suffix="%"></aegov-progress>

JavaScript Updates

Value and description can be updated dynamically via JavaScript.

Click to simulate upload progress
const progress = document.querySelector('#js-progress');

// Update value
progress.value = 50;

// Update description
progress.description = 'Uploading file 10 of 20...';

Indeterminate to Determinate

Start indeterminate, then switch to a known progress value.

<!-- Start indeterminate -->
<aegov-progress id="my-progress" description="Connecting..."></aegov-progress>

<script>
  // Switch to determinate
  const progress = document.querySelector('#my-progress');
  progress.value = 0;
  progress.description = 'Downloading...';
</script>

API Reference

Properties

Property Attribute Type Default Description
value value number — Current value. Omit for indeterminate state.
max max number 100 Maximum value.
height height string '2' Tailwind spacing scale (each unit = 0.25rem). Default "2" = 0.5rem = 8px.
counter counter 'top' | 'trailing' — Counter placement. Hidden when not set.
counterSuffix counter-suffix string '' Suffix appended directly to counter value. No auto spacing.
description description string — Description text below the progress bar.
fieldId field-id string auto ID for the native progress element. Auto-generated if not set.
class class string — Additional CSS classes for the wrapper.
