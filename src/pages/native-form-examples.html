Native Form Elements

Every native HTML form element styled by the design system's global CSS. These are not components, these are native form elements that must appear to have inherited the design system itself.

1. Text Inputs

Standard text-based input types styled by the design system's global CSS. These are the most common input elements that exist in the browser.

<input type="text" placeholder="Enter text"> <input type="email" placeholder="user@example.com"> <input type="password" placeholder="Enter password"> <input type="url" placeholder="https://example.com"> <input type="tel" placeholder="+971 50 123 4567"> <input type="search" placeholder="Search...">

2. Number Input

Numeric input with optional min, max, and step attributes.

<input type="number" placeholder="0"> <input type="number" min="0" max="100" step="5" placeholder="0">

3. Date & Time Inputs

Native browser date and time picker inputs.

<input type="date"> <input type="time"> <input type="datetime-local"> <input type="month"> <input type="week">

4. Checkbox

Standard checkboxes for selecting one or more options from a set.

<label> <input type="checkbox" name="services" value="web"> <span>Web Development</span> </label> <!-- Checked --> <input type="checkbox" checked> <!-- Disabled --> <input type="checkbox" disabled> <!-- Indeterminate (via JavaScript) --> <input type="checkbox" id="cb"> <script>document.getElementById('cb').indeterminate = true;</script>

5. Radio Buttons

Radio buttons for selecting exactly one option from a set.

<label> <input type="radio" name="emirate" value="abudhabi"> <span>Abu Dhabi</span> </label> <!-- Selected --> <input type="radio" name="group" checked> <!-- Disabled --> <input type="radio" name="group" disabled>

6. Toggle Switch

A toggle will always be a checkbox input at its core, but with custom styles to make it look like a switch. For this purpose, a toggle will always be a component and not a native element.

7. Other Input Types

Range slider, color picker, and file upload inputs.

Accepts multiple files
accept="image/*"
<input type="range" min="0" max="100" value="50"> <input type="color" value="#0284c7"> <input type="file"> <input type="file" multiple> <input type="file" accept="image/*">

8. Textarea

Multi-line text input styled by global CSS.

<textarea rows="4" placeholder="Enter your message..."></textarea>

9. Select

Native dropdown select and multi-select elements.

Hold Ctrl/Cmd to select multiple
<select> <option value="" disabled selected>Choose an option</option> <option value="option1">Option 1</option> </select> <select multiple size="5"> <option value="html">HTML</option> <option value="css">CSS</option> </select>

10. Datalist (Autocomplete)

A text input with a predefined list of suggestions via the <datalist> element.

<input type="text" list="frameworks" placeholder="Type to search..."> <datalist id="frameworks"> <option value="Angular"> <option value="React"> <option value="Vue"> </datalist>

11. Output, Meter & Progress

Native form output, meter gauge, and progress bar elements.

+ = 75
6 out of 10
9 out of 10
70%
Loading...
<output for="a b">75</output> <meter min="0" max="10" low="3" high="7" optimum="5" value="6"></meter> <progress value="70" max="100">70%</progress> <progress>Loading...</progress> <!-- indeterminate -->

12. Input States

Disabled, readonly, required, and error states on native inputs.

* Required field

Please enter a valid email address.

<input type="text" value="Cannot edit this" disabled> <input type="text" value="Read only value" readonly> <input type="text" placeholder="Required" required> <input type="email" value="invalid-email"> <!-- with error wrapper --> <input type="text" maxlength="20"> <input type="text" pattern="[A-Za-z]+">
