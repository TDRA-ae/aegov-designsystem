8. Multiple Dropdowns - Singleton Pattern

When one dropdown opens, all others automatically close. This prevents overlapping dropdowns and improves UX.

Third Menu Try it!
<!-- Only one dropdown can be open at a time --> <aegov-dropdown> <button>Dropdown 1</button> <div slot="dropdown-content">...</div> </aegov-dropdown> <aegov-dropdown> <button>Dropdown 2</button> <div slot="dropdown-content">...</div> </aegov-dropdown>

11. Nested Dropdown (Submenu)

Create nested dropdowns by placing a dropdown trigger inside another dropdown's content. The nested dropdown opens to the right.

Dropdown with Submenu
Dashboard Profile Settings ›
General Security Privacy Notifications Appearance
More Options ›
Help Center Documentation API Reference Keyboard Shortcuts
Logout
<aegov-dropdown> <button>Main Menu</button> <div slot="dropdown-content"> <a href="#">Dashboard</a> <!-- Nested Dropdown --> <aegov-dropdown position="right" align="start" trigger-type="hover"> <a href="#"> Settings <span>›</span> </a> <div slot="dropdown-content"> <a href="#">General</a> <a href="#">Security</a> <a href="#">Privacy</a> </div> </aegov-dropdown> <a href="#">Logout</a> </div> </aegov-dropdown>

💡 Nested Dropdown Tips

  • Use position="right" for nested dropdowns to open them to the side
  • Set trigger-type="hover" for better UX with nested menus
  • Reduce show-delay (e.g., 100ms) for quicker submenu response
  • Add visual indicators (like ›) to show items have submenus
  • Nested dropdowns work great for complex navigation menus

📚 Complete API Documentation

Properties

Property Type Default Description
triggerType 'click' | 'hover' 'click' How the dropdown is triggered - click or hover
position 'top' | 'right' | 'bottom' | 'left' 'bottom' Position of dropdown relative to trigger. Auto-flips if not enough space.
align 'start' | 'center' | 'end' 'start' Alignment of dropdown relative to trigger
gap number 8 Gap between dropdown and trigger element (in pixels)
offset number 0 Additional offset for dropdown positioning (in pixels)
showDelay number 200 Delay before showing dropdown (in milliseconds, hover only)
hideDelay number 0 Delay before hiding dropdown (in milliseconds, hover only)
disabled boolean false Whether the dropdown is disabled

Events

Event Name Detail Type Description
aegovDropdownOpen void Emitted when the dropdown opens
aegovDropdownClose void Emitted when the dropdown closes

Slots

Slot Name Description
(default) Trigger element - button, link, or any HTML element that opens the dropdown
dropdown-content Content displayed in the dropdown. Supports any HTML. Width automatically fits content with minimum 12rem.

Methods

Method Description
closeDropdown() Programmatically close the dropdown. Useful for closing dropdowns from external triggers.

Usage Examples

// Basic dropdown <aegov-dropdown> <button>Click Me</button> <div slot="dropdown-content"> <a href="#">Menu Item</a> </div> </aegov-dropdown> // Hover trigger with custom positioning <aegov-dropdown trigger-type="hover" position="top" align="center" show-delay="300"> <button>Hover Me</button> <div slot="dropdown-content"> Appears above, centered </div> </aegov-dropdown> // With custom gap and offset <aegov-dropdown gap="16" offset="20"> <button>Custom Spacing</button> <div slot="dropdown-content">...</div> </aegov-dropdown> // Programmatic close (JavaScript) const dropdown = document.querySelector('aegov-dropdown'); dropdown.closeDropdown();
⚠️ Important Notes:

• Only one dropdown can be open at a time (singleton pattern)
• Dropdown auto-closes when clicking inside content or outside
• Width automatically adjusts to content (min-width: 12rem)
• Keyboard navigation: Escape to close, Tab/Arrow keys to navigate
• Focus trap enabled - focus stays within dropdown when open
• Portal rendering - dropdown content renders to document.body
• Viewport collision detection - auto-flips position if not enough space
• Accessible with proper ARIA attributes (aria-haspopup, aria-expanded, aria-controls)
