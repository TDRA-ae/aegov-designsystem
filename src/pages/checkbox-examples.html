Checkbox Component

Interactive checkbox component with grouping, variants, and check-all support.

Basic Checkbox

<aegov-checkbox label="Accept terms and conditions" name="terms" value="accepted"></aegov-checkbox>

Checkbox with Description

<aegov-checkbox
  label="Subscribe to newsletter"
  description="Get weekly updates about new features and improvements."
  name="newsletter"
  value="subscribe"
></aegov-checkbox>

Checkbox in Form Field (with aegov-label)

I agree to the privacy policy 
<aegov-form-field>
  <aegov-checkbox name="privacy" value="agreed"></aegov-checkbox>
  <aegov-label>I agree to the privacy policy</aegov-label>
</aegov-form-field>

Sizes

Three sizes available: sm (16px), base (18px, default), and lg (20px). Size can be set on individual checkboxes or propagated from a group.

Individual Checkboxes

<aegov-checkbox size="sm" label="Small checkbox"></aegov-checkbox>
<aegov-checkbox size="base" label="Base checkbox"></aegov-checkbox>
<aegov-checkbox size="lg" label="Large checkbox"></aegov-checkbox>

Group Size Propagation

Setting size on the group propagates it to all child checkboxes.

Small Group

Large Group

<aegov-checkbox-group size="sm" label="Small group">
  <aegov-checkbox label="Option A" value="a"></aegov-checkbox>
  ...
</aegov-checkbox-group>

API Reference

aegov-checkbox

Property Attribute Type Default Description
fieldId field-id string Auto-generated Unique ID for the native checkbox element.
name name string — The name attribute for the checkbox.
value value string — The value attribute for the checkbox.
checked checked boolean false Whether the checkbox is checked.
size size 'sm' | 'base' | 'lg' 'base' The size of the checkbox. Controls checkbox dimensions, label font size, and description font size.
disabled disabled boolean false Whether the checkbox is disabled.
required required boolean false Whether the checkbox is required.
label label string — Label text. When provided, generates an associated <label> element.
description description string — Description text displayed below the label. Only rendered when label is provided.
checkAll check-all boolean false Marks this checkbox as a "check all" controller within a group.
indeterminate indeterminate boolean false Whether the checkbox is in an indeterminate state. Managed by parent group for check-all.
class class string — Additional CSS classes to apply.

aegov-checkbox Events

Event Detail Description
aegovCheckboxChange { checked: boolean; value?: string } Emitted when the checkbox checked state changes.

aegov-checkbox-group

Property Attribute Type Default Description
variant variant 'default' | 'list' | 'cards' | 'pills' 'default' Visual variant for the group layout.
orientation orientation 'vertical' | 'horizontal' 'vertical' Stack direction for checkbox items.
label label string — Optional label rendered as a <legend> for accessibility.
size size 'sm' | 'base' | 'lg' 'base' Size of all checkboxes in the group. Propagated to all child checkboxes.
disabled disabled boolean false Disables all checkboxes within the group via native <fieldset> disabled.
class class string — Additional CSS classes to apply.

aegov-checkbox-group Events

Event Detail Description
aegovCheckboxGroupChange { values: string[] } Emitted when any checkbox in the group changes. Contains all currently checked values.

Accessibility

Standalone checkbox without label

When using aegov-checkbox without the label prop, the native input has no accessible name. You must provide an aria-label attribute on the host element for screen reader support.

<!-- Correct: standalone checkbox with aria-label -->
<aegov-checkbox aria-label="Accept terms" name="terms" value="accepted"></aegov-checkbox>

<!-- Correct: using the label prop (accessible by default) -->
<aegov-checkbox label="Accept terms" name="terms" value="accepted"></aegov-checkbox>

<!-- Incorrect: no accessible name -->
<aegov-checkbox name="terms" value="accepted"></aegov-checkbox>

Built-in accessibility features

  • When label is provided, the checkbox is wrapped in a <label> for implicit association
  • When description is provided, it is linked to the input via aria-describedby
  • When required is set, aria-required="true" is added to the native input
  • All aria-* attributes on the host element are passed through to the native input
  • Group uses semantic <fieldset> + <legend> for screen reader grouping
  • Native keyboard navigation: Tab to focus, Space to toggle
