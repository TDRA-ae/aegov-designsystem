Code Examples

Basic Usage

<aegov-callout variant="success" appearance="soft"> <div slot="content"> <div class="text-lg font-bold mb-2">Success!</div> <p>Your changes have been saved.</p> </div> </aegov-callout>

With Custom Icon

<aegov-callout variant="info" appearance="soft"> <svg slot="icon" class="size-6" xmlns="...">...</svg> <div slot="content"> <p>Custom icon example</p> </div> </aegov-callout>

With Actions

<aegov-callout variant="warning" appearance="soft"> <div slot="content"> <p>Unsaved changes detected.</p> </div> <div slot="actions"> <div class="flex gap-4"> <button>Save</button> <button>Discard</button> </div> </div> </aegov-callout>

All Features Combined

<aegov-callout variant="error" appearance="solid" bordered dismissible> <svg slot="icon" class="size-6">...</svg> <div slot="content"> <div class="text-lg font-bold mb-2">Error Title</div> <p>Error description</p> </div> <a href="#" slot="link">Learn More</a> <div slot="actions"> <button>Retry</button> </div> </aegov-callout>

Props Reference

Prop Type Default Description
variant string 'default' 'default' | 'error' | 'warning' | 'success' | 'info'
appearance string 'soft' 'soft' | 'solid'
dismissible boolean false Shows close button to dismiss callout
bordered boolean false Adds border around callout

Slots

Slot Description
icon Custom icon (optional, defaults to variant-appropriate icon)
content Main content of the callout
link Action link in top-right corner
actions Action buttons at bottom (automatically spaced with mt-8)

Events

Event Description
aegovCalloutDismiss Fired when the callout is dismissed via close button
