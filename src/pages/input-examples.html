A form field with label and input. The label is automatically linked to the input via the for attribute.

Three size options: sm, base (default), and lg.

Input can be disabled or readonly to prevent user interaction.

Disabled Input Readonly Input

5. Icon Slots

Pass SVG icons via slot="icon-start" and slot="icon-end". Icons render inside the input border and support click interactions. When password-toggle or copyable is active, icon-end is ignored.

Search (icon-start) Email (icon-start) Amount (icon-end) Both Icons (start + end)

6. Icon Slots - Sizes

Icon containers automatically match the input height. Control icon size via classes on the SVG.

Small (sm) Base (default) Large (lg)

7. Icon Slots - Priority

Password toggle and copyable features always take priority over icon-end. The icon-start slot is always shown.

Password with icon-start (icon-end ignored) Copyable with icon-start (icon-end ignored)

8. Icon Slots - Clickable Icons

Slotted icons support click interactions. Wrap your SVG in a <button> for accessible clickable icons.
