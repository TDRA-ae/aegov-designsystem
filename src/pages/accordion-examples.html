📚 API Documentation

Accordion (Parent) Properties

Property Attribute Type Default Description
allowMultiple allow-multiple boolean false Whether multiple accordion items can be open at the same time
defaultOpen default-open number undefined Index of the accordion item to open by default (0-based)
icon icon 'chevron' | 'plus' 'chevron' Icon style for accordion items
bordered bordered boolean false Whether to show border around the accordion

Accordion Item (Child) Properties

Property Attribute Type Default Description
disabled disabled boolean false Whether the accordion item is disabled
open open boolean false Whether the accordion item is open (internal, set by parent)

Events

Event Description Detail Type
aegovAccordionItemToggle Emitted when an accordion item is toggled { open: boolean }

Slots

Slot Component Description
(default) aegov-accordion Accordion items (aegov-accordion-item elements)
accordion-item-heading aegov-accordion-item Heading content for the accordion item
accordion-item-content aegov-accordion-item Content that expands/collapses

Usage Example

<!-- Basic Accordion -->
<aegov-accordion>
  <aegov-accordion-item>
    <span slot="accordion-item-heading">Question 1</span>
    <span slot="accordion-item-content">Answer 1</span>
  </aegov-accordion-item>
  <aegov-accordion-item>
    <span slot="accordion-item-heading">Question 2</span>
    <span slot="accordion-item-content">Answer 2</span>
  </aegov-accordion-item>
</aegov-accordion>

<!-- Allow Multiple Open -->
<aegov-accordion allow-multiple>
  <aegov-accordion-item>...</aegov-accordion-item>
  <aegov-accordion-item>...</aegov-accordion-item>
</aegov-accordion>

<!-- Plus Icon -->
<aegov-accordion icon="plus">
  <aegov-accordion-item>...</aegov-accordion-item>
</aegov-accordion>

<!-- Default Open Item -->
<aegov-accordion default-open="0">
  <aegov-accordion-item>...</aegov-accordion-item>
</aegov-accordion>

<!-- Bordered Style -->
<aegov-accordion bordered>
  <aegov-accordion-item>...</aegov-accordion-item>
</aegov-accordion>

<!-- Disabled Item -->
<aegov-accordion>
  <aegov-accordion-item>...</aegov-accordion-item>
  <aegov-accordion-item disabled>...</aegov-accordion-item>
</aegov-accordion>
// JavaScript API - Listen to toggle events
const accordion = document.querySelector('aegov-accordion');
const items = accordion.querySelectorAll('aegov-accordion-item');

items.forEach((item) => {
  item.addEventListener('aegovAccordionItemToggle', (event) => {
    console.log('Item toggled:', event.detail.open);
  });
});

Important Notes

  • Parent-Child Pattern: aegov-accordion-item must be used inside aegov-accordion. It cannot be used standalone.
  • Single vs Multiple Mode: By default, only one item can be open. Use allow-multiple to allow multiple items to be open simultaneously.
  • Nested Accordions: Fully supports nested accordion structures for hierarchical content organization.
  • Keyboard Navigation: Use Enter or Space keys to toggle accordion items when focused.
  • Accessibility: Includes proper ARIA attributes (aria-expanded) for screen reader support.
  • RTL Support: Icons and text automatically adjust for right-to-left languages.
