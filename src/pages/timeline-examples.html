aegov-timeline

Step-based timeline indicator showing completed, active, and pending steps in a multi-step workflow. Supports horizontal and vertical layouts, compact dot variant, and multiple sizes.

Horizontal & Vertical Default & Compact 3 Sizes Accessible Responsive

1 Basic Horizontal (Default)

The default layout renders numbered circles connected by lines. Completed steps show a checkmark, the active step is outlined, and pending steps are grayed out.

7 Compact with Tooltips

Wrap each step in an aegov-tooltip to reveal step details on hover. Since compact horizontal mode hides labels, tooltips provide a lightweight way to surface context. Add the .timeline-tooltip-wrap class to each tooltip to preserve the flex layout.

Hover over each dot to see step details

Account Setup Identity Verification Document Upload Application Review Final Approval
<style> .timeline-tooltip-wrap { flex: 1 1 0%; min-width: 0; display: block; } .timeline-tooltip-wrap .aegov-tooltip-trigger { display: flex; width: 100%; } .timeline-tooltip-wrap aegov-timeline-step { flex: 1 1 0%; min-width: 0; } </style> <aegov-timeline variant="compact"> <aegov-tooltip class="timeline-tooltip-wrap" content="Step 1 — Completed" position="top"> <aegov-timeline-step status="completed">Step 1</aegov-timeline-step> </aegov-tooltip> <aegov-tooltip class="timeline-tooltip-wrap" content="Step 2 — Active" position="top"> <aegov-timeline-step status="active">Step 2</aegov-timeline-step> </aegov-tooltip> <aegov-tooltip class="timeline-tooltip-wrap" content="Step 3 — Pending" position="top"> <aegov-timeline-step status="pending">Step 3</aegov-timeline-step> </aegov-tooltip> </aegov-timeline>
Integration Note:

When wrapping timeline steps with tooltips, the tooltip host element sits between the flex container and the step. The .timeline-tooltip-wrap helper class ensures all three layers (tooltip host, trigger div, step host) stretch correctly so connector lines remain connected.

API Documentation

aegov-timeline Properties

Property Type Default Description
variant TimelineVariant 'default' Visual variant: 'default' (numbered circles) or 'compact' (small dots)
size TimelineSize 'base' Indicator size: 'sm', 'base', or 'lg'
orientation TimelineOrientation 'horizontal' Layout direction: 'horizontal' or 'vertical'

aegov-timeline-step Properties

Property Type Default Description
status TimelineStepStatus 'pending' Step state: 'completed', 'active', or 'pending'
description string undefined Optional subtitle text displayed below the label

Slots

Component Slot Description
aegov-timeline default aegov-timeline-step elements
aegov-timeline-step default Step label text
aegov-timeline-step icon Custom icon (replaces the number or checkmark inside the circle)

Important Notes:

Parent required: aegov-timeline-step must be placed inside aegov-timeline. Using it standalone will throw an error.

Props are managed by parent: The parent automatically passes variant, size, orientation, step index, and connector style to each child. You only need to set status and optionally description on each step.

Connector logic: Connectors between steps are solid when the preceding step is completed, and dashed otherwise.

No interaction: This component is purely visual. It does not emit click events or manage navigation between steps.
