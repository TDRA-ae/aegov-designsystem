📚 API Documentation

Properties

Property Type Default Description
href string required The URL that the link points to
target LinkTarget undefined Target attribute (_blank, _self, _parent, _top)
rel string undefined Rel attribute (auto "noopener noreferrer" for target="_blank")
class string undefined Additional CSS classes to apply to the link

Events

Event Detail Type Description
aegovLinkClick { href: string; event: MouseEvent } Emitted when link is clicked. Call event.preventDefault() to stop navigation.

Pass-Through Attributes

Attribute Pattern Example Description
data-* data-tracking-id="123" Custom data attributes for metadata and tracking
aria-* aria-label="Descriptive label" ARIA attributes for accessibility
title title="Tooltip text" Tooltip that appears on hover
id id="unique-link-id" Unique identifier for the link element

📝 Important Notes:

Security: Links with target="_blank" automatically receive rel="noopener noreferrer" for security unless you provide a custom rel attribute.

Styling: Links inherit global styling from the design system. Use the class prop to add additional Tailwind utilities or custom classes.

Events: The aegovLinkClick event allows you to intercept navigation for SPA routing or analytics. Call preventDefault() on event.detail.event to stop default navigation.

Accessibility: All links are keyboard accessible and support screen readers. Use aria-label for icon-only links or when additional context is needed.
