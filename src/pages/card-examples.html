aegov-card

A skeleton card component — a styled container with responsive rounded borders, configurable padding, border widths, backgrounds, and hover effects.

2 Disabling Padding

Padding (1.5rem / 24px) is on by default. Use disallow-padding to remove it — useful when content like images needs to bleed to the card edges.

Default (with padding)

Cards have 1.5rem inner padding by default.

disallow-padding

Padding removed. Content manages its own spacing.

API Documentation

aegov-card Properties

Property Attribute Type Default Description
disallowPadding disallow-padding boolean false Disables the default 1.5rem (24px) inner padding
borderWidth border-width 1 | 2 | 3 1 Border thickness in pixels
borderStyle border-style 'standard' | 'creative' 'standard' Standard: solid primary-600. Creative: gradient from primary-400 to primary-800
background background 'white' | 'transparent' | 'subtle' 'white' Background style. Subtle uses slate-50
hover hover 'off' | 'standard' | 'glow' 'off' Hover effect. Standard changes border color; glow adds a shadow

Slots

Slot Description
(default) All card content. Any custom HTML is accepted.

Visual Behavior

Feature Details
Border color primary-600 (default), primary-500 on hover
Border radius 1rem (desktop), 0.75rem (≤ 768px), 0.5rem (≤ 480px)
Glow effect Multi-layered box-shadow with primary color at low opacity, larger spread at bottom
Transitions 300ms ease on border-color and box-shadow
Note: The card is a skeleton container. It does not enforce any internal layout — all content structure is up to the consumer via the default slot. Padding (1.5rem) is included by default. Use disallow-padding when you need edge-to-edge content like images.
