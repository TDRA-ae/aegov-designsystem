API Reference

aegov-radio

Property Attribute Type Default Description
fieldId field-id string Auto-generated Unique ID for the native radio element.
name name string — The name attribute. Radios with the same name form a single-select group.
value value string — The value attribute for the radio.
checked checked boolean false Whether the radio is checked.
size size 'sm' | 'base' | 'lg' 'base' The size of the radio.
disabled disabled boolean false Whether the radio is disabled.
required required boolean false Whether the radio is required.
label label string — Label text. When provided, generates an associated <label> element.
description description string — Description text displayed below the label.
class class string — Additional CSS classes to apply.

aegov-radio Events

Event Detail Description
aegovRadioChange { checked: boolean; value?: string } Emitted when the radio checked state changes.

aegov-radio-group

Property Attribute Type Default Description
variant variant 'default' | 'list' | 'cards' | 'pills' 'default' Visual variant for the group layout.
orientation orientation 'vertical' | 'horizontal' 'vertical' Stack direction for radio items.
label label string — Optional label rendered as a <legend> for accessibility.
name name string Required Shared name for all radios. Ensures native single-select behavior.
size size 'sm' | 'base' | 'lg' 'base' Size of all radios in the group. Propagated to all children.
disabled disabled boolean false Disables all radios within the group via native <fieldset> disabled.
class class string — Additional CSS classes to apply.

aegov-radio-group Events

Event Detail Description
aegovRadioGroupChange { value: string | undefined } Emitted when the selected radio changes. Contains the selected value.

Accessibility

Standalone radio without label

When using aegov-radio without the label prop, the native input has no accessible name. You must provide an aria-label attribute on the host element for screen reader support.

<!-- Correct: standalone radio with aria-label -->
<aegov-radio aria-label="Option A" name="group" value="a"></aegov-radio>

<!-- Correct: using the label prop (accessible by default) -->
<aegov-radio label="Option A" name="group" value="a"></aegov-radio>

Built-in accessibility features

  • When label is provided, the radio is wrapped in a <label> for implicit association
  • When description is provided, it is linked to the input via aria-describedby
  • When required is set, aria-required="true" is added to the native input
  • All aria-* attributes on the host element are passed through to the native input
  • Group uses semantic <fieldset> with role="radiogroup" + <legend>
  • Native keyboard navigation: Tab to focus group, Arrow keys to move between radios
