Separator Component

A flexible separator for visually dividing sections of content with support for horizontal/vertical orientations, text labels, and accessibility features.

Component API

The separator component provides a semantic way to divide content sections with full accessibility support.

Property Type Default Description
orientation 'horizontal' | 'vertical' 'horizontal' Orientation of the separator line
variant 'default' | 'subtle' 'default' Visual style variant (subtle has lighter color)
text string undefined Optional text label displayed at the center
decorative boolean true Whether separator is decorative (role="presentation") or semantic (role="separator")

10. Accessibility Features

By default, separators are decorative (role="presentation"). Set decorative="false" for semantic separators that screen readers should announce.

This separator is purely visual and will be ignored by screen readers.

Semantic Separator

This separator is semantic and will be announced by screen readers as "separator".

Best Practices

  • Use horizontal separators for vertical stacking of content sections
  • Use vertical separators for side-by-side content in toolbars or flex layouts
  • Add text labels when the separator represents a meaningful division (e.g., "or", "more options")
  • Use subtle variant for secondary divisions within already-separated sections
  • Keep decorative by default unless the separator has semantic meaning important for screen reader users
  • Use in menus to group related actions together
  • Combine with headings in forms to clearly separate different sections
