Select

A Select lets users choose one or more options from a list. The AEGOV select supports two render modes — a real native <select> for simple cases and form submission, and a custom listbox for richer experiences with search, multi-select, grouped options, and a clear button. Options are declared as light DOM children using aegov-select-option and optionally wrapped in aegov-select-option-group.

Introduction

The aegov-select component composes a parent select with one or more aegov-select-option children. The default appearance="default" renders a true native <select> (best for simple lists, mobile, and form submission). The appearance="listbox" renders a styled custom dropdown panel that supports searching, multi-selection, and grouped options. Setting is-multiple="true" automatically forces the listbox appearance.

<aegov-select label="Ministry" placeholder="Select a ministry" name="ministry">
  <aegov-select-option value="moi">Ministry of Interior</aegov-select-option>
  <aegov-select-option value="mof">Ministry of Finance</aegov-select-option>
  <aegov-select-option value="moh">Ministry of Health and Prevention</aegov-select-option>
  <aegov-select-option value="moe">Ministry of Education</aegov-select-option>
  <aegov-select-option value="moj">Ministry of Justice</aegov-select-option>
</aegov-select>
Ministry of Interior Ministry of Finance Ministry of Health and Prevention Ministry of Education Ministry of Justice

The dropdown panel for the listbox appearance is positioned beneath the trigger and dynamically chooses to open above or below depending on the available viewport space. It remains anchored to the trigger and closes automatically when focus leaves the component or the user presses Escape.

Variants

The appearance property switches the underlying rendering.

Default — native <select>

The default appearance renders a real <select> element. It is the right choice for simple lists, optimal mobile UX (the OS native picker is used), and unambiguous form submission. Searching and multi-selection are not available in this mode.

  <aegov-select-option value="ad">Abu Dhabi</aegov-select-option>
  <aegov-select-option value="dxb">Dubai</aegov-select-option>
  <aegov-select-option value="shj">Sharjah</aegov-select-option>
  <aegov-select-option value="ajm">Ajman</aegov-select-option>
  <aegov-select-option value="uaq">Umm Al Quwain</aegov-select-option>
  <aegov-select-option value="rak">Ras Al Khaimah</aegov-select-option>
  <aegov-select-option value="fuj">Fujairah</aegov-select-option>

Listbox — custom dropdown

The listbox appearance renders a styled trigger button and a positioned dropdown panel. Use it when you need search, multi-selection, grouped options, or a clear button. The panel is anchored to the trigger and chooses its open direction based on viewport space.

  <aegov-select-option value="visa">Visa &amp; residency</aegov-select-option>
  <aegov-select-option value="vehicle">Vehicle registration</aegov-select-option>
  <aegov-select-option value="health">Health insurance</aegov-select-option>
  <aegov-select-option value="education">Education &amp; training</aegov-select-option>

Variant

The variant property selects the colour family for the trigger ring, the value text, and the selected option fill in the open list. The focus ring stays primary-support-600 (camel) and the error border stays aered-600 regardless of variant.

  • primary — primary-* family (default)
  • secondary — secondary-* family
  • neutral-max — strong neutral (aeblack-800 family)
  • neutral-min — quiet neutral (aeblack-100 family). Selected option fill stays aeblack-800 for legibility.

Multi-select

Set is-multiple="true" to allow more than one option to be selected. The trigger shows a count summary ("3 selected") and each option in the panel renders with a checkbox. Multi-select forces the listbox appearance.

Set is-clearable="true" to display a small "×" inside the trigger that clears the current selection when activated. Particularly useful in optional filters where users need to undo a choice without reopening the panel.

Events

Event Component Detail Description
aegovSelectChange aegov-select { value: string | string[]; label: string | string[] } Fires when the selected value changes.
aegovSelectOpen aegov-select void Fires when the listbox dropdown opens (listbox appearance only).
aegovSelectClose aegov-select void Fires when the listbox dropdown closes (listbox appearance only).

Validation

aegov-select exposes the unified Validation Surface. Select-specific notes only:

Variants and form participation

Variant Form mechanism
default (native) Inner native <select name> submits naturally. aria-invalid set on <select>.
listbox (custom) FormAssociated via ElementInternals.setFormValue(). aria-invalid set on the trigger <button>.

For is-multiple listbox, the FormData payload contains one entry per selected value (not a comma-joined string). Schemas should match:

Common recipes

Required selection:

<aegov-select name="country" is-required>
  <aegov-select-option value="ae">UAE</aegov-select-option>
</aegov-select>

Conditional required (depends on another field):

toggle.addEventListener('aegovValidate', () => {
  select.isRequired = toggle.isChecked;
  select.validate('change');
});

Programmatic clear:

await select.setCustomValidity('');
select.value = '';

Accessibility

Built-in behaviour

  • The default appearance renders a real <select>, so it inherits all native accessibility — keyboard support, type-ahead, OS-level mobile pickers, and screen reader announcements.
  • The listbox appearance uses the WAI-ARIA combobox pattern: the trigger has role="combobox", aria-haspopup="listbox", aria-expanded, aria-controls pointing at the panel, and aria-required when is-required is set; the panel has role="listbox"; each option has role="option" and aria-selected; and aria-activedescendant tracks the focused option as the user types.
  • Grouped options use role="group" and aria-labelledby to associate the group header with its members.
  • The search input declares role="searchbox" and links to the listbox with aria-controls. Its aria-label and placeholder are bilingual (English and Arabic) — no developer translation needed.
  • The clear button's aria-label is bilingual. No developer translation needed.
  • Error messages are announced via aria-live="polite" only after the first genuine blur (when focus leaves the component entirely, not when it moves to the internal search input or listbox options). This avoids premature error announcements while the user is still selecting.
  • Disabled options are skipped during keyboard navigation and announce as disabled.

Developer responsibilities

  • Provide a meaningful placeholder and pair the select with an aegov-label linked via field-id so the control has a programmatic label.
  • Use the default (native) appearance whenever search and multi-select are unnecessary — it is faster, lighter, and gives the best mobile experience.
  • For long lists (countries, services, time slots) prefer is-searchable="true" so users can filter with the keyboard.
  • Keep option labels concise. The trigger truncates long single-select labels and shows a count for multi-select; hidden labels become invisible to mouse users.

Keyboard support (listbox appearance)

Key Action
Enter, Space, ↓ Open the dropdown when closed.
↑ / ↓ Move focus to the previous / next enabled option.
Home / End Jump to the first / last enabled option.
Enter / Space Select the focused option (in single mode this also closes the dropdown).
Escape Close the dropdown and return focus to the trigger.
Type characters Filter the list when is-searchable is enabled.
Tab / Shift + Tab Move focus to the next / previous focusable element.

Default-appearance keyboard support is provided by the browser's native <select> implementation.
