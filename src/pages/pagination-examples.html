Pagination

Navigate through paged content with accessible, flexible pagination controls.

1. Basic Pagination

Default pagination with Previous and Next buttons and smart page range.

Controlled component: aegov-pagination does not track the current page internally. Listen to aegovPageChange and update current-page yourself.

Default (10 pages, page 5)

<aegov-pagination total-pages="10" current-page="5" ></aegov-pagination>

First page (Previous disabled)

Last page (Next disabled)

2. First & Last Buttons

Add show-first-last to display dedicated buttons for jumping to the first and last page.

With First & Last (page 5 of 20)

<aegov-pagination total-pages="20" current-page="5" show-first-last ></aegov-pagination>

On first page (First button disabled)

On last page (Last button disabled)

3. Sizes

Three size variants: sm, base (default), and lg.

Small (sm)

Base (default)

<aegov-pagination ... size="base"></aegov-pagination>

Large (lg)

<aegov-pagination ... size="lg"></aegov-pagination>

4. Controlling Visible Pages

Use sibling-count and boundary-count to control the range algorithm.

siblingCount=1, boundaryCount=1 (defaults, page 10 of 30)

siblingCount=2, boundaryCount=1 (more siblings, page 10 of 30)

<aegov-pagination total-pages="30" current-page="10" sibling-count="2" boundary-count="1" ></aegov-pagination>

siblingCount=1, boundaryCount=2 (more boundaries, page 15 of 30)

Small range — no ellipsis (5 pages)

5. Disabled State

Use the disabled prop to prevent all interaction (e.g., while loading data).

Disabled pagination

<aegov-pagination total-pages="10" current-page="5" disabled ></aegov-pagination>

6. Custom Labels

Customise the text on navigation buttons for different languages or branding needs.

Abbreviated English labels

<aegov-pagination prev-label="Prev" next-label="Next" show-first-last first-label="First" last-label="Last" ></aegov-pagination>

10. Accessibility

Built to WCAG 2.1 AA standards.

  • Wrapped in <nav aria-label="Pagination"> as a landmark region.
  • Page list uses <ul> + <li> for semantic list semantics.
  • Active page button carries aria-current="page".
  • All buttons have descriptive aria-label values (e.g. "Go to page 3", "Go to previous page").
  • Disabled buttons have both the native disabled attribute and aria-disabled="true".
  • Ellipsis spans are marked aria-hidden="true" — they are decorative only.
  • SVG icons carry aria-hidden="true"; meaning comes from the button's aria-label.
  • Directional icons flip with CSS transform: scaleX(-1) in RTL contexts.
  • Keyboard-navigable: Tab through buttons, Enter / Space to activate.
