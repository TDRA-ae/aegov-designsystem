API Documentation

Properties

Property Attribute Type Default Description
size size 'xs' | 'sm' | 'base' | 'lg' | 'xl' | '2xl' | '3xl' 'base' The avatar size (xs: 24px, sm: 32px, base: 40px, lg: 48px, xl: 56px, 2xl: 64px, 3xl: 80px)
variant variant 'rounded' | 'square' 'rounded' The avatar shape (rounded = circular, square = rounded corners)
src src string undefined Image URL for the avatar. If not provided, shows fallback slot content.
alt alt string 'Avatar' Alt text for the avatar image (accessibility)
status status 'online' | 'offline' undefined Optional status indicator (green dot for online, gray for offline)

Events

This component does not emit any custom events.

Slots

Slot Description
(default) Fallback content shown when no src is provided (text initials, icons, emojis, or any HTML)
