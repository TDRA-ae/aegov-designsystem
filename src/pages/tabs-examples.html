Keyboard Navigation

Full ARIA tabs pattern implemented for screen reader and keyboard accessibility.

Key Action
Tab Move focus into the active tab, then Tab again to enter the panel
→ / ← Move between tabs in horizontal orientation (cycles at ends). Direction reverses in RTL
↓ / ↑ Move between tabs in vertical orientation (cycles at ends)
Home Jump to first non-disabled tab
End Jump to last non-disabled tab
