🔔 Callout Component

Alert and notification component with multiple variants, appearances, and interactive features

5 Variants 2 Appearances Custom Icons Action Slots Dismissible Bordered Option RTL Support Accessibility

1. All Variants (Soft Appearance)

The callout component comes in 5 semantic variants with default soft appearance.

Default, Error, Warning, Success, Info
Default Callout: This is a standard informational message for general notices. Error: There was a problem processing your request. Please try again. Warning: Your session will expire in 5 minutes. Please save your work. Success: Your changes have been saved successfully! Information: New features are available. Check out our latest updates.

2. Solid Appearance

Use appearance="solid" for bold, high-contrast callouts that demand attention.

Solid Variants
Critical Error: System maintenance required immediately. Important Warning: This action cannot be undone. Deployment Complete: Application is now live in production. System Update: Scheduled maintenance tonight from 10 PM to 12 AM.
<aegov-callout variant="error" appearance="solid"> <span slot="content"><strong>Critical Error:</strong> System maintenance required.</span> </aegov-callout>

3. Bordered Callouts

Add bordered attribute to include a border around the callout for better visual separation.

Soft with Border

4. Dismissible Callouts

Enable the dismissible property to allow users to close the callout. Listen to aegovCalloutDismiss event.

Dismissible Examples
Cookie Notice: We use cookies to improve your experience. Click the X to dismiss this notice. Limited Time Offer: Special pricing ends tonight at midnight.
<aegov-callout variant="info" dismissible> <span slot="content">Cookie Notice: We use cookies to improve your experience.</span> </aegov-callout>

📚 Complete API Documentation

Properties

Property Type Default Description
variant 'default' | 'error' | 'warning' | 'success' | 'info' 'default' The semantic variant of the callout, determines the color scheme and default icon
appearance 'soft' | 'solid' 'soft' The appearance style. Soft has light background, Solid has dark background with white text
dismissible boolean false Whether the callout can be dismissed with a close button
bordered boolean false Whether to display a border around the callout

Events

Event Name Detail Type Description
aegovCalloutDismiss void Emitted when the dismiss button is clicked. The callout hides itself automatically.

Slots

Slot Name Description
icon Custom icon to display. If not provided, a default icon based on variant is shown.
content Main content of the callout. Supports rich HTML including lists, bold text, and formatting.
actions Action buttons displayed below the content. Wrap buttons in a div for proper spacing.
link Optional link displayed on the right side of the callout (before dismiss button if present).

Usage Examples

// Basic callout <aegov-callout variant="info"> <span slot="content">This is an informational message.</span> </aegov-callout> // Dismissible with solid appearance <aegov-callout variant="warning" appearance="solid" dismissible> <span slot="content">Important warning that can be dismissed.</span> </aegov-callout> // With actions and link <aegov-callout variant="success"> <span slot="content">Update available!</span> <div slot="actions"> <aegov-button size="sm">Update Now</aegov-button> <aegov-button size="sm" variant="outline">Later</aegov-button> </div> <a slot="link" href="/changelog">View Changes →</a> </aegov-callout> // Custom icon <aegov-callout variant="default"> <svg slot="icon">...custom SVG...</svg> <span slot="content">Callout with custom icon.</span> </aegov-callout> // Event handling (JavaScript) const callout = document.querySelector('aegov-callout'); callout.addEventListener('aegovCalloutDismiss', () => { console.log('User dismissed the callout'); localStorage.setItem('calloutDismissed', 'true'); });
⚠️ Important Notes:

• Dismissible callouts hide automatically when the close button is clicked
• Each variant has a default icon (error: circle-X, warning: triangle, success: checkmark, info: info-circle, default: info-outline)
• The actions slot buttons inherit colors from the callout variant for visual consistency
• Callouts automatically support RTL layout with proper icon and button positioning
• Use role="alert" is applied automatically for accessibility
