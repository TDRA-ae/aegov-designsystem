Datepicker

Single date and date range selection with presets, constraints, localization, and accessibility support.

1. Basic Single Date

Default datepicker in single mode. Click to open the calendar and select a date.

<aegov-datepicker></aegov-datepicker> <aegov-datepicker placeholder="Choose a date"></aegov-datepicker> <aegov-datepicker value="2026-03-15"></aegov-datepicker> <aegov-datepicker disabled value="2026-03-15"></aegov-datepicker>

2. Custom Date Formats

Configure the output format using tokens: YYYY, YY, MM, M, DD, D, MMM, MMMM, dd, ddd.

<aegov-datepicker format="DD/MM/YYYY" value="2026-03-15"></aegov-datepicker> <aegov-datepicker format="MM-DD-YYYY" value="2026-03-15"></aegov-datepicker> <aegov-datepicker format="D/M/YYYY" value="2026-03-05"></aegov-datepicker> <aegov-datepicker format="DD MMM YYYY" value="2026-03-15"></aegov-datepicker>

3. Date Constraints

Restrict selectable dates with min, max, disable-future, and unavailable-dates.

<aegov-datepicker min="2026-03-10"></aegov-datepicker> <aegov-datepicker max="2026-03-20"></aegov-datepicker> <aegov-datepicker disable-future></aegov-datepicker> <aegov-datepicker unavailable-dates="2026-03-10,2026-03-15,2026-03-20"></aegov-datepicker>

4. Week Start Day

Configure which day starts the week (0=Sunday, 1=Monday, 6=Saturday).

<aegov-datepicker start-day="0"></aegov-datepicker> <aegov-datepicker start-day="1"></aegov-datepicker> <aegov-datepicker start-day="6"></aegov-datepicker>

5. Header Variants

Toggle between selectable dropdowns and static month/year labels.

<aegov-datepicker></aegov-datepicker> <aegov-datepicker selectable-header="false"></aegov-datepicker>

6. With Confirmation

Require explicit Apply/Cancel action before committing the selection.

<aegov-datepicker with-confirmation></aegov-datepicker> <aegov-datepicker mode="range" with-confirmation></aegov-datepicker>

7. Date Range Selection

Two-month side-by-side calendar for selecting a start and end date.

<aegov-datepicker mode="range"></aegov-datepicker> <aegov-datepicker mode="range" value="2026-03-01 / 2026-03-15"></aegov-datepicker> <aegov-datepicker mode="range" range-placeholder-start="Check-in" range-placeholder-end="Check-out"></aegov-datepicker>

8. Range Limits

Set minimum and maximum number of days for range selection.

<aegov-datepicker mode="range" min-range="3"></aegov-datepicker> <aegov-datepicker mode="range" max-range="7"></aegov-datepicker> <aegov-datepicker mode="range" min-range="3" max-range="14"></aegov-datepicker>

9. Range Presets

Quick-select preset date ranges from a sidebar panel.

<aegov-datepicker mode="range" presets="today,yesterday,last7Days,last30Days,thisMonth,lastMonth"> </aegov-datepicker>

10. Custom Trigger

Replace the built-in input with a custom trigger element using the "trigger" slot.

Pick a Date
<aegov-datepicker> <aegov-button slot="trigger" variant="outline" size="sm">Pick a Date</aegov-button> </aegov-datepicker>

11. Event Handling

Listen to change, open, close, clear, and month-change events.

12. Programmatic Methods — Single Mode

Control the datepicker via JavaScript methods: open(), close(), clear(), getValue(). In single mode, getStartDate(), getEndDate(), and getPreset() return false.

open() close() clear() getValue() getStartDate() getEndDate() getPreset()
const dp = document.querySelector('aegov-datepicker'); // Control methods await dp.open(); await dp.close(); await dp.clear(); // Data retrieval const value = await dp.getValue(); // "2026-06-15" const start = await dp.getStartDate(); // false (single mode) const end = await dp.getEndDate(); // false (single mode) const preset = await dp.getPreset(); // false (single mode)

13. Programmatic Methods — Range Mode

In range mode, getStartDate() and getEndDate() return the formatted date strings. getPreset() returns the matching preset ID if the current selection matches a configured preset.

getValue() getStartDate() getEndDate() getPreset() clear()
const dp = document.querySelector('aegov-datepicker[mode="range"]'); const value = await dp.getValue(); // "2026-03-01 / 2026-03-15" const start = await dp.getStartDate(); // "2026-03-01" or false const end = await dp.getEndDate(); // "2026-03-15" or false const preset = await dp.getPreset(); // "last7Days" or false

14. RTL Support

Full right-to-left layout support for Arabic and Hebrew locales.

15. API Reference

Complete property, event, and method documentation for the aegov-datepicker component.

Properties

Property Attribute Type Default Description
mode mode 'single' | 'range' 'single' Selection mode: single date or date range.
value value string '' Pre-selected value. Single: "YYYY-MM-DD". Range: "YYYY-MM-DD / YYYY-MM-DD".
format format string 'YYYY-MM-DD' Output format using tokens: YYYY, YY, MM, M, DD, D, MMM, MMMM, dd, ddd.
placeholder placeholder string 'Select date' Placeholder text for single mode input.
rangePlaceholderStart range-placeholder-start string 'Start date' Placeholder for range start input.
rangePlaceholderEnd range-placeholder-end string 'End date' Placeholder for range end input.
min min string '' Minimum selectable date (ISO string or "today").
max max string '' Maximum selectable date (ISO string or "today").
disableFuture disable-future boolean false Disable all future dates (shorthand for max="today").
startDay start-day number 0 Week start day: 0=Sunday, 1=Monday, ... 6=Saturday.
locale locale string 'en' Locale for day/month names (BCP 47, e.g. 'en', 'ar', 'fr').
minRange min-range number 0 Minimum number of days for range selection.
maxRange max-range number 0 Maximum number of days for range selection (0 = unlimited).
unavailableDates unavailable-dates string '' Comma-separated ISO dates that cannot be selected.
presets presets string '' Comma-separated preset IDs for range mode (e.g. "today,last7Days,thisMonth").
disabled disabled boolean false Whether the datepicker is disabled.
clearable clearable boolean true Show clear button when a value is set.
selectableHeader selectable-header boolean true Show month/year select dropdowns in calendar header.
withConfirmation with-confirmation boolean false Show Apply/Cancel buttons for confirming selection.
yearRangeStart year-range-start number 0 Start year for the year dropdown (default: current year - 100). Must be set together with yearRangeEnd.
yearRangeEnd year-range-end number 0 End year for the year dropdown (default: current year + 100). Must be set together with yearRangeStart.

Events

Event Detail Description
aegovDatepickerChange DatepickerChangeDetail Emitted when a date or range is selected. Detail includes value (string), date (Date, single mode), startDate and endDate (Date, range mode).
aegovDatepickerOpen void Emitted when the calendar opens.
aegovDatepickerClose void Emitted when the calendar closes.
aegovDatepickerClear void Emitted when the value is cleared.
aegovDatepickerMonthChange DatepickerMonthChangeDetail Emitted when the visible month/year changes. Detail includes month (0-indexed) and year.

Methods

Method Returns Description
open() Promise<void> Opens the calendar programmatically. No-op if disabled.
close() Promise<void> Closes the calendar programmatically.
clear() Promise<void> Clears the current value and emits aegovDatepickerClear.
getValue() Promise<string> Returns the formatted value. Single: "YYYY-MM-DD". Range: "YYYY-MM-DD / YYYY-MM-DD". Empty string if no value.
getStartDate() Promise<string | false> Returns the formatted start date in range mode. Returns false in single mode or if no start date is set.
getEndDate() Promise<string | false> Returns the formatted end date in range mode. Returns false in single mode or if no end date is set.
getPreset() Promise<string | false> Returns the preset ID matching the current range selection (e.g. "last7Days"). Returns false in single mode, if no presets are configured, or if the selection doesn't match any preset.

Format Tokens

Use these tokens in the format property to customize date output.

Token Output Example
YYYY 4-digit year 2026
YY 2-digit year 26
MMMM Full month name March
MMM Short month name Mar
MM Zero-padded month 03
M Month number (no padding) 3
DD Zero-padded day 05
D Day number (no padding) 5
ddd Short weekday name Mon
dd Min weekday name Mo
