4 Positioning Modes

Control banner positioning: static (in page flow), fixed (viewport), or sticky (scrolls then sticks).

Static Position (Default)

Banner appears in normal document flow.

This is a static banner that flows with the page content.
⚙️ Position Options:

display="static" - Normal document flow (demonstrated above)

display="fixed" - Fixed to viewport top/bottom, always visible

display="sticky" - Scrolls with page, then sticks to top/bottom

position="top" - Attach to top of viewport/page

position="bottom" - Attach to bottom of viewport/page

mode="push" - Pushes content down (adds body padding)

mode="overlay" - Floats over content

<!-- Static banner (in page flow) --> <aegov-banner display="static">Content</aegov-banner> <!-- Fixed to top of viewport --> <aegov-banner display="fixed" position="top" mode="push">Content</aegov-banner> <!-- Fixed to bottom, overlays content --> <aegov-banner display="fixed" position="bottom" mode="overlay">Content</aegov-banner> <!-- Sticky banner --> <aegov-banner display="sticky" position="top">Content</aegov-banner>

9 Accessibility Features

Built-in accessibility support with ARIA roles, live regions, and keyboard navigation.

Alert Role (Auto-detected)

Error variants automatically receive role="alert" for screen readers.

✓ role="alert" ✓ aria-live="assertive"

Region Role (Default)

Info and other variants use role="region" for semantic grouping.

✓ role="region" ✓ aria-live="polite"

Keyboard Accessibility

All interactive elements are keyboard accessible. Tab to the dismiss button and action buttons, then press Enter or Space to activate. Action

✓ Tab navigation ✓ Enter/Space activation ✓ Focus indicators

♿ Accessibility:

Banners automatically receive appropriate ARIA roles based on variant (error/success = "alert", others = "region"). Screen readers announce banners with aria-live regions. All buttons are keyboard accessible with visible focus indicators.

📚 API Documentation

Properties

Property Type Default Description
variant CalloutVariant 'default' Color scheme: 'default', 'info', 'success', 'warning', 'error'
appearance CalloutAppearance 'soft' Visual style: 'soft' (subtle) or 'solid' (bold)
position BannerPosition 'top' Vertical position: 'top' or 'bottom'
display BannerDisplay 'fixed' Positioning: 'static', 'fixed', or 'sticky'
mode BannerMode 'push' Layout mode: 'push' (adds padding) or 'overlay' (floats over)
dismissible boolean true Whether the banner can be closed
aria-role BannerRole auto ARIA role (auto-computed from variant if not specified)
banner-title string undefined Title for aria-labelledby attribute
auto-focus boolean false Auto-focus the banner when mounted (critical alerts only)

Events

Event Detail Type Description
aegovBannerDismiss void Emitted when the banner is dismissed
aegovBannerHeightChange number Emitted when banner height changes (overlay mode)

Slots

Slot Description
default Main banner content (text, HTML)
actions Action buttons (aegov-button elements)

📝 Important Notes:

Positioning Modes: "static" = normal flow, "fixed" = viewport-locked, "sticky" = scrolls then sticks

Layout Modes: "push" adds body padding (for fixed/sticky), "overlay" floats over content

Auto ARIA: error/success variants get role="alert", others get role="region"

Height Management: Fixed banners in push mode automatically adjust body padding. Listen to aegovBannerHeightChange for overlay mode.

Dismissible: Set dismissible="false" for critical messages that users shouldn't close
