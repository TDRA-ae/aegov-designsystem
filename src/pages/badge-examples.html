Usage Examples

Basic Usage

<!-- Default badge -->
<aegov-badge>Default</aegov-badge>

<!-- With color -->
<aegov-badge color="primary">Primary</aegov-badge>

<!-- With size -->
<aegov-badge size="lg">Large</aegov-badge>

<!-- Solid appearance -->
<aegov-badge appearance="solid" color="aegold">Gold</aegov-badge>

<!-- Combined props -->
<aegov-badge size="sm" appearance="solid" color="aered">Critical</aegov-badge>

Dismissible Badges

Badges can be made dismissible by adding the dismissible attribute. This adds a close button that emits the aegovBadgeDismiss event when clicked. Note: The badge does not automatically hide itself - you control what happens when dismissed.

<script>
  // Listen for dismiss event
  const badge = document.getElementById('myBadge');
  badge.addEventListener('aegovBadgeDismiss', (event) => {
    console.log('Badge dismissed!');

    // Option 1: Remove from DOM
    event.target.remove();

    // Option 2: Hide with animation
    event.target.style.transition = 'opacity 0.3s';
    event.target.style.opacity = '0';
    setTimeout(() => event.target.remove(), 300);
