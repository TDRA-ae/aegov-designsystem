📚 API Documentation

Properties

Property Attribute Type Default Description
open open boolean false Whether the modal is currently open/visible
position position 'center' | 'top' | 'bottom' 'center' Position of the modal on screen
backdropOpacity backdrop-opacity 'light' | 'base' | 'dark' 'base' Backdrop opacity level
closeWithBackdrop close-with-backdrop boolean true Whether clicking the backdrop closes the modal
preventBodyScroll prevent-body-scroll boolean true Whether to prevent body scroll when modal is open
ℹ️ Note: The ESC key always closes the modal (non-configurable for accessibility compliance)

Events

Event Description Detail Type
aegovModalOpen Emitted when modal is opened void
aegovModalClose Emitted when modal is closed void
aegovModalBeforeClose Emitted before modal closes (cancellable) { preventDefault: () => void }
aegovModalBackdropClick Emitted when backdrop is clicked MouseEvent
aegovModalEscapePress Emitted when ESC key is pressed KeyboardEvent

Methods

Method Description Returns
show() Programmatically open the modal Promise<void>
close() Programmatically close the modal Promise<void>
toggle() Toggle modal open/closed state Promise<void>

Slots

Slot Description
(default) Modal content - can contain any HTML elements

Usage Example

<!-- Basic Modal -->
<aegov-modal id="myModal">
  <div style="padding: 2rem;">
    <h2>Modal Title</h2>
    <p>Modal content here.</p>
    <button onclick="document.getElementById('myModal').close()">
      Close
    </button>
  </div>
</aegov-modal>

<button onclick="document.getElementById('myModal').show()">
  Open Modal
</button>
// JavaScript API
const modal = document.getElementById('myModal');

// Open modal
await modal.show();

// Close modal
await modal.close();

// Toggle modal
await modal.toggle();

// Listen to events
modal.addEventListener('aegovModalOpen', () => {
  console.log('Modal opened!');
});

modal.addEventListener('aegovModalClose', () => {
  console.log('Modal closed!');
});

// Prevent closing
modal.addEventListener('aegovModalBeforeClose', (event) => {
  if (hasUnsavedChanges()) {
    event.detail.preventDefault();
    alert('Please save your changes first!');
  }
});
