Avatar Group Component

Group multiple avatars with default (spaced) or compact (overlapping) layouts, plus an optional "+N" more indicator

← Back to Components

Default Mode (Spaced)

Avatars are spaced apart with a uniform gap. This is the default layout mode.

<aegov-avatar-group> <aegov-avatar variant="rounded" src="user1.jpg" alt="User 1"></aegov-avatar> <aegov-avatar variant="rounded" src="user2.jpg" alt="User 2"></aegov-avatar> <aegov-avatar variant="rounded" src="user3.jpg" alt="User 3"></aegov-avatar> </aegov-avatar-group>

Compact Mode (Overlapping)

Avatars overlap each other with a white ring for visual separation. The overlap amount scales with the avatar size.

<aegov-avatar-group mode="compact"> <aegov-avatar variant="rounded" src="user4.jpg"></aegov-avatar> <aegov-avatar variant="rounded" src="user5.jpg"></aegov-avatar> <aegov-avatar variant="rounded" src="user6.jpg"></aegov-avatar> <aegov-avatar variant="rounded" src="user7.jpg"></aegov-avatar> </aegov-avatar-group>

"More" Indicator

When more-count is greater than 0, a "+N" button appears at the end. You can also provide custom text with more-text.

Default "+N" text

<aegov-avatar-group more-count="12"> ...avatars </aegov-avatar-group>

Compact with more

<aegov-avatar-group mode="compact" more-count="24"> ...avatars </aegov-avatar-group>

Custom more text

<aegov-avatar-group mode="compact" more-count="99" more-text="99 others"> ...avatars </aegov-avatar-group>

Sizes

The size prop is enforced on all child avatars and the "more" indicator. Seven sizes are available from XS (24px) to 3XL (80px).

XS (24px)
SM (32px)
Base (40px) - default
LG (48px)
XL (56px)
2XL (64px)
3XL (80px)
<!-- Size is enforced on all children --> <aegov-avatar-group mode="compact" size="lg" more-count="5"> <aegov-avatar variant="rounded" src="user1.jpg"></aegov-avatar> <aegov-avatar variant="rounded" src="user2.jpg"></aegov-avatar> <aegov-avatar variant="rounded" src="user3.jpg"></aegov-avatar> </aegov-avatar-group>

Square Variant

The variant prop controls the shape of the "more" indicator button. Set it to "square" to match square avatars.

Rounded (default)

<aegov-avatar-group variant="rounded" ...>

Square

<aegov-avatar-group variant="square" ...>

Dark Background

Use the --avatar-group-ring-color CSS variable to match the ring color to dark backgrounds so the overlap separation blends in.

<!-- Set the ring color to match the background --> <div style="background: #1e293b; --avatar-group-ring-color: #1e293b;"> <aegov-avatar-group mode="compact" more-count="15" size="lg"> <aegov-avatar variant="rounded" src="..."></aegov-avatar> <aegov-avatar variant="rounded" src="..."></aegov-avatar> </aegov-avatar-group> </div>

Fallback Avatars

When no image is provided, avatars render with the default user icon. Works seamlessly in both modes.

All fallback

Mixed (images + fallback)

Event Handling

Click the "+N" indicator to fire the aegovAvatarGroupMore event. Use this to open a popover, modal, or list of remaining users.

<aegov-avatar-group id="group" mode="compact" more-count="25"> ...avatars </aegov-avatar-group> <script> document.getElementById('group') .addEventListener('aegovAvatarGroupMore', () => { // Open a modal/popover listing remaining users console.log('Show all users'); }); </script>

API Documentation

Properties

Property Attribute Type Default Description
mode mode 'default' | 'compact' 'default' Layout mode. default spaces avatars with a gap; compact overlaps them with a ring separator.
size size 'xs' | 'sm' | 'base' | 'lg' | 'xl' | '2xl' | '3xl' 'base' Enforced on every child <aegov-avatar> and the "more" indicator button.
variant variant 'rounded' | 'square' 'rounded' Shape applied to the "more" indicator button. Match this to your avatar variant.
moreCount more-count number 0 Number of additional users. When > 0, displays the "+N" indicator button.
moreText more-text string "{moreCount}+" Custom display text for the more indicator. Overrides the default "+N" format.

Events

Event Type Description
aegovAvatarGroupMore CustomEvent<void> Emitted when the "more" indicator button is clicked. Use this to show a list, popover, or modal of remaining users.

Slots

Slot Description
(default) <aegov-avatar> elements to be grouped together

CSS Custom Properties

Variable Default Description
--avatar-group-ring-color white Ring color used in compact mode to separate overlapping avatars and on the "more" button. Set this to match dark backgrounds.
