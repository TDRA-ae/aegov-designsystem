🔘 Button Group Component

Visually group related buttons with seamless border handling and flexible orientation.

📖 API Documentation

aegov-button-group

Property Type Default Description
orientation 'horizontal' | 'vertical' 'horizontal' The orientation of the button group

Notes

  • Only direct <aegov-button> children are grouped
  • First button: keeps left/top border-radius (horizontal/vertical)
  • Last button: keeps right/bottom border-radius (horizontal/vertical)
  • Middle buttons: no border-radius
  • Borders collapse using negative margins to prevent double borders
  • All button props (variant, size, appearance) work normally

8. Accessibility Features

Button groups include built-in accessibility features:

  • role="group" - Groups buttons semantically for screen readers
  • Keyboard Navigation - All buttons are keyboard accessible with Tab/Enter
  • Focus Indicators - Clear visual focus states on all buttons
  • Button Events - All aegovButtonClick events work normally
  • ARIA Support - Compatible with aria-* attributes on individual buttons
Accessible Button Group A- A A+
<aegov-button-group> <aegov-button variant="solid" appearance="primary" aria-label="Decrease">A-</aegov-button> <aegov-button variant="solid" appearance="primary" aria-label="Default">A</aegov-button> <aegov-button variant="solid" appearance="primary" aria-label="Increase">A+</aegov-button> </aegov-button-group>

9. Best Practices

✅ Do's

  • Use button groups for logically related actions
  • Keep button text concise and action-oriented
  • Maintain consistent button size and variant within a group
  • Use horizontal groups for toolbars and inline actions
  • Use vertical groups for menus and dropdown-like layouts
  • Indicate the currently selected state visually (solid vs outline)

❌ Don'ts

  • Don't mix different button sizes in the same group
  • Don't use more than 5-7 buttons in a horizontal group (UX)
  • Don't nest button groups within button groups
  • Don't use non-button elements as direct children
  • Don't rely on button order alone to indicate importance
